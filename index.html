☁ 云备份
把手机记录备份到你的 GitHub Gist（私密）。换手机时：在新手机装本应用、填同一个 Gist ID，点「从云端恢复」即可找回全部记录。只有一台手机在用，不会出现同步冲突。
GitHub Token （仅 gist 权限）
用 classic token，只勾 gist scope。创建：github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token。随时可在 GitHub 吊销。
Gist ID （首次留空自动创建；换手机时填原来的）
首次点下方按钮会自动建一个私密 Gist 并上传本机记录；Gist ID 请另存一处（如手机备忘录），换手机要用。
备份 / 恢复
把本机当前记录整份覆盖到云端。新增/修改记录后会自动备份，也可手动点这里立即备份。
拉取云端记录，与本机合并（按时间较新者为准，不会丢本机现有的）。换手机/重装时用。
